# Ainterest
>Today, can you still tell where you end and AI begins?

Shanzhai Web Project by Xinyue Xu

## Short Description
Ainterest is a shanzhai website that imitates the interface and recommendation logic of Pinterest. By simulating algorithmic suggestions and AI-driven inspiration, the project questions the boundaries between human creativity and machine influence.
## Concept
Pinterest has long been a platform people always turn to for inspiration: you start a project from collecting pictures on this platform to make a moodboard that reflect personal taste and intention. Increasingly, however, AI tools have begun to occupy a similar role. You ask AI to brainstorm with you so that you can get more "inspirations". 

By capturing the similarity between these two, **Ai**nterest attempts to materialize the presence of AI in the process of creative inspiration by recreating a visual environment similar to Pinterest. Through this imitation, the project invites viewers to reflect on the relationship between humans and AI: as AI technologies gradually become more powerful, where does individual creativity end, and where does the influence of AI begin? If we have been aware of this invisible guidance, can we truly resist it, or are we already part of the system?
